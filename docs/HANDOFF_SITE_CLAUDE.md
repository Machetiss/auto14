## Цель сайта (слова Сергея)

## Устройство сайта
- Next.js 14 App Router, TypeScript, Tailwind, Prisma + SQLite, нео-брутализм.
- Прод: Docker на Amvera, деплой = push в remote `amvera`. БД SQLite создаётся и сидируется при сборке образа.
- Заявки: 3 формы (BookingModal, ContactForm, SpinWheelPopup) → `/api/leads` → SQLite + Telegram + Google Sheets.
- Метрика: счётчики 106881681 (основной) и 91798480 (Яндекс Бизнес).

- В Schema жёстко прописан рейтинг 5.0 / 165 отзывов — нужно сверить с реальными карточками.
