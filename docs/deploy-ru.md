# Инструкция по переезду на российский хостинг (auto-14.ru)

Этот документ описывает процесс миграции сайта с Vercel на российскую инфраструктуру для обеспечения 100% доступности из РФ без VPN.

## Вариант 1: Amvera Cloud (Рекомендуемый)

Это самый простой способ, аналогичный Vercel, но с серверами в России.

1. **Регистрация**: Создайте аккаунт на [amvera.ru](https://amvera.ru/).
2. **Создание проекта**:
   - Нажмите "Создать проект".
   - Выберите "Подключить GitHub" и выберите ваш репозиторий `auto14`.
   - Сервис автоматически обнаружит `amvera.yml` и `Dockerfile`, которые я подготовил.
3. **Настройка переменных**:
   - В разделе "Переменные окружения" добавьте все ключи из вашего `.env` (Telegram токены, URL сайта и т.д.).
4. **Домен**:
   - В панели Amvera добавьте домен `auto-14.ru`.
   - Вам будет выдана инструкция для DNS (обычно это A-запись или CNAME).
5. **DNS (в Cloudflare или REG.RU)**:
   - Обновите A-запись на IP, который выдаст Amvera.

## Вариант 2: Свой VPS (Selectel / Timeweb)

Для тех, кто хочет полный контроль и выделенный IP.

1. **Аренда сервера**: Купите самый простой VPS (Ubuntu 22.04+) в российском дата-центре.
2. **Установка Docker**:
   ```bash
   curl -fsSL https://get.docker.com -o get-docker.sh
   sh get-docker.sh
   ```
3. **Запуск сайта**:
   - Склонируйте репозиторий: `git clone https://github.com/Machetiss/auto14.git`
   - Соберите образ: `docker build -t auto14 .`
   - Запустите контейнер:
     ```bash
     docker run -d -p 80:3000 --env-file .env --name auto14-site auto14
     ```
4. **Обновление DNS**: Направьте домен на IP вашего нового сервера.

---

### Почему это сработает?
- **Российские IP**: Провайдеры и РКН не блокируют трафик внутри страны.
- **Docker**: Я настроил `Dockerfile` так, чтобы сайт работал на любой Linux-машине идентично локальной версии.
- **Standalone**: Next.js теперь собирается в легковесный пакет, оптимизированный для серверов.
