## 🚘 Проект 1: Сайт автосервиса «Авто14» (auto-14.ru)

### 🎯 Цели и задачи
1. **Захват локального рынка**: получение до 70% целевых заявок на ремонт авто в Казани (микрорайон Константиновка).
2. **Лидерство в AI-поиске**: оптимизация под поисковые движки ИИ (Yandex Alice, ChatGPT, Perplexity) по 50+ ключевым запросам.
3. **Рост конверсии**: увеличение конверсии посетителей в заявки на 200% в течение 6 месяцев.
4. **Комплексное присутствие**: Сайт + Карты/Справочники + Отзывы.

### 🛠 Стек технологий
* **Фреймворк**: Next.js 14 (App Router)
* **Язык**: TypeScript
* **Стилизация**: Tailwind CSS 3.3 + Vanilla CSS (дизайн-система с токенами в `app/globals.css`).
* **База данных**: SQLite (файл `prisma/dev.db`), доступ через Prisma ORM.
* **Иконки**: Lucide React.
* **Деплой**: Amvera Cloud (российский хостинг для работы без VPN из РФ), конфигурация через `amvera.yml` и `Dockerfile`.

### 📂 Структура проекта
* `/app` — маршрутизация и страницы (App Router).
  * `page.tsx` — главная страница автосервиса.
  * `/uslugi` — хаб услуг.
  * `/razval-shozhdenie`, `/remont-podveski`, `/zamena-masla`, `/diagnostika`, `/shinomontazh` — специализированные страницы услуг с оптимизированной структурой (FAQ, цены, отзывы).
  * `/kontakty` — страница контактов.
  * `/otzyvy` — страница отзывов.
  * `/blog` — раздел со статьями.
* `/components` — переиспользуемые UI-компоненты.
  * `Footer.tsx` и `Navbar.tsx` — подвал и шапка сайта.
  * `/ui` — базовые элементы (кнопка `Button.tsx`, контейнер `Container.tsx`).
* `/data` — статические файлы данных (`carBrands.ts`, `reviews.ts`, `services.ts`, `faqs.ts`).
* `/prisma` — схема БД (`schema.prisma`), скрипт наполнения (`seed.ts`), а также файл БД `dev.db`.
* `/docs` — документация проекта (аудиты, планы тестирования, инструкции по деплою).
* `/public` — статические ресурсы (картинки, иконки, фавиконы).
* `package.json`, `tailwind.config.ts`, `next.config.js` — конфигурационные файлы.

### 📐 Дизайн и UI/UX (Важные правила)
* **Стиль**: Сайт выполнен в стиле **Neo-Brutalism** (нео-брутализм).
* **Токены и Цвета** (описаны в `app/globals.css`):
  * Бренд-желтый: `--brand-yellow: #FFF500;`
  * Акцентный оранжевый (для кнопок): `--accent-orange: #FF4500;`
  * Фоновый темный: `--bg-dark: #111111;`
  * Текст: белый/черный с жесткими черными рамками (`border-2 border-black`).
  * Жесткие тени кнопок: `box-shadow: 4px 4px 0px 0px var(--brand-black);` c анимацией сдвига при наведении и нажатии.
* **Принципы**: Mobile-First, высокая производительность (LCP < 3с), SEO и Schema.org структурированные данные (AutoRepair, Service, Review, FAQPage).

## 📊 Проект 2: База данных авто-фильтров (`data/Auto_Filters_DB.csv`)

### 🎯 Суть задачи
Заполнение и поддержка базы данных по подбору моторного масла, объемов заливки и артикулов фильтров (масляный, воздушный, салонный) для различных марок и моделей автомобилей.

### 📋 Правила заполнения (строгий алгоритм для агента)
1. **Поиск информации**: Использовать `tavily_search` для нахождения точных характеристик по связке: `brand` + `model` + `year_from` + `year_to`.
2. **Что искать**:
   * Все модификации двигателей (`engine_volume`) для указанной модели и периода.
   * Тип топлива (`fuel_type` - бензин / дизель / гибрид / электро).
   * Официальные допуски моторного масла (`oil_specs`).
   * Заправочный объем масла (`oil_fill_liters`) в литрах.
   * Артикулы фильтров MANN: `filter_oil_mann` (масляный), `filter_air_mann` (воздушный), `filter_cabin_mann` (салонный).
3. **Разделение строк**: Если у одной модели есть несколько существенно разных двигателей (например, 1.6 и 2.0 с разным объемом масла и фильтрами) — создать отдельную строку для каждого двигателя.
4. **Фиксированные значения** (никогда не менять и не искать альтернативы):
   * `oil_ngn_5w30_product` = `NGN PROFI 5W-30`
   * `oil_ngn_5w30_article` = `V172085301`
   * `oil_ngn_5w40_product` = `NGN GOLD 5W-40`
   * `oil_ngn_5w40_article` = `V172085302`
   * `filter_oil_lynx`, `filter_oil_sufix` = `нет данных`
   * `filter_air_lynx`, `filter_air_sufix` = `нет данных`
   * `filter_cabin_lynx`, `filter_cabin_sufix` = `нет данных`
   * `notes` = `Заполнено агентом`
5. **Если данных нет**: Писать строго `нет данных`, ничего не придумывать.
6. **Формат CSV**: Разделитель строго `;`, кодировка UTF-8.

## 🤖 Проект 3: Телеграм-бот Gallup CliftonStrengths

Находится в папке `scripts/`.
* `generate_gallup.py` — генерирует структуру вопросов (`gallup_questions.json`) для теста на определение сильных сторон.
* `gallup_bot.py` — код Телеграм-бота на библиотеке `pyTelegramBotAPI` (`telebot`). Бот проводит опрос из 177 вопросов, фиксирует результаты и выгружает пользователю JSON-файл с ответами для последующего анализа ИИ.
* Для работы бота требуется указать токен в переменной `TOKEN` внутри `gallup_bot.py`.

## 🔄 Инструкции по поиску недостающей информации

1. **Если нет локальных переменных (`.env`)**:
   * Проверить файл `.env.example` на наличие необходимых переменных.
   * Попросить пользователя скопировать `.env.local` или предоставить нужные токены (например, для Telegram бота или базы данных).
2. **Если база данных SQLite пуста**:
   * Попросить пользователя запустить миграции и сидирование командой:
     `npx prisma migrate dev`
     а затем:
     `npx tsx prisma/seed.ts` (или `npm run build` который автоматически запускает prisma generate).
3. **Если требуются изменения в UI/UX**:
   * Обязательно проверить `app/globals.css` и существующие компоненты в `components/ui/Button.tsx`, чтобы сохранить стилистику нео-брутализма.
   * Согласовать изменения с пользователем перед написанием кода.
4. **Если нужно проверить сборку Next.js**:
   * Объяснить пользователю команду для ручного запуска сборки:
     `npm run build`
     и попросить прислать вывод терминала в случае ошибок.
